## Method and limitations

A deterministic execution plan built from the governed files, sorted corpus and approved query configuration binds each required slot to its own raw result. The validator checks role, analysis, comparison side, phase, corpus/test/query, closure inputs, RDF graph identity, compiler and command arguments before deriving any classification. A summary cannot select a different raw execution. Incoming serialized graphs are checked independently of blank-node labels.

Fresh reasoner executions use a create-once pre-execution ticket with a random challenge. The ticket-consuming wrapper checks exact graph/query bytes and the required slot, launches Java, and creates a separate captured-output artifact and sealed result envelope. The validator checks the selected invocation ID, ticket, envelope, captured stdout/stderr and derived result. `javac` and `java -version` are toolchain setup checks governed by their existing command/input/output records; they are not semantic reasoner slots. This local custody prevents post-hoc output rebinding while tickets, envelopes and the selected-invocations record remain intact. It is not cryptographic nonrepudiation against an actor who can rewrite every local file; that stronger threat requires external or write-once custody.

PROV-style approximate deductive difference: HermiT materializes all non-reflexive named class/object-property subsumptions and equivalences, then compares baseline with aligned entailments separately inside each original logical signature. Built-in top/bottom entities are excluded; foreign names referenced in the baseline remain in its logical signature. Equivalence contributes both subclass/subproperty directions plus one canonical equivalence pair. This is not full model-theoretic conservativity. No claim of methodological novelty or equivalence to a 312-instance corpus is made.

Every example uses all four current source modules; aligned runs add CCO merged (which embeds BFO) and `SSN2BFO.ttl`. Only import directives are removed from temporary, explicitly expanded graphs. All logical triples, including functionality and inverse functionality, are retained. Missing imports, OWL 2 DL violations, reasoner errors, timeouts and absent materializations fail closed. Consistency results on an incomplete or out-of-profile local graph are diagnostic only.
