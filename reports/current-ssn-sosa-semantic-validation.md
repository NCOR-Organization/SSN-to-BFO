The validator checks role, analysis, comparison side, phase, corpus/test/query, closure inputs, RDF graph identity, compiler and command arguments before deriving any classification. PROV-style approximate deductive difference: HermiT materializes all non-reflexive named class/object-property subsumptions and equivalences, then compares baseline with aligned entailments separately inside each original logical signature. Built-in top/bottom entities are excluded; foreign names referenced in the baseline remain in its logical signature. Equivalence contributes both subclass/subproperty directions plus one canonical equivalence pair. This is not full model-theoretic conservativity. No claim of methodological novelty or equivalence to a 312-instance corpus is made.

Every example uses all four current source modules; aligned runs add CCO merged (which embeds BFO) and `SSN2BFO.ttl`. Only import directives are removed from temporary, explicitly expanded graphs. All logical triples, including functionality and inverse functionality, are retained. Missing imports, OWL 2 DL violations, reasoner errors, timeouts and absent materializations fail closed. Consistency results on an incomplete or out-of-profile local graph are diagnostic only.
